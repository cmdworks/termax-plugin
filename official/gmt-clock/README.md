# GMT Clock Plugin

A simple status bar plugin for Termax that displays the current Greenwich Mean Time (GMT/UTC) in real-time.

## Features

- 🕒 **Live GMT Time**: Updates every second seamlessly in your status bar.
- ⚡ **Zero Permissions**: Pure WebAssembly calculation requiring no system or network access.
- 🪶 **Ultra Lightweight**: Microsecond runtime overhead.
